# Control Plane

Layanan vendor untuk identity, tenant, entitlement, placement, dan release registry SaaS. Ia tidak memiliki domain data bisnis module.

Database Core bernama `core_erp`. Katalog module resmi dapat dilihat di `/control/modules` atau melalui `GET /api/v1/control/modules`.

Rujukan: [grand design](../../docs/dev/01-grand-design.md), [release lifecycle](../../docs/dev/03-release-and-on-prem.md), dan [target worktree](../../docs/dev/06-worktree-target.md).
