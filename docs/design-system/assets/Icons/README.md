# Icons

Ikon Lucide versi 0.475.0 (lisensi ISC) yang dipakai komponen bersama, satu berkas SVG per ikon: kanvas 24 × 24, garis 2px, ujung dan sudut membulat, tanpa isian.

- **Satu tinta, `currentColor`.** Saat ditanam langsung ke halaman, ikon mengikuti warna teks di sekitarnya (`primary` di bar perintah, `muted-foreground` di header kolom). Saat dimuat sebagai gambar, ikon tampil hitam; atur warnanya dengan menanam SVG-nya, bukan dengan filter.
- Ukuran: 14px di bar perintah dan menu kolom, 16px bawaan, 12px di tombol kecil dan Badge, 24px di kotak ikon Empty.
- Set lengkap Lucide tersedia untuk hampir semua stack; ikon menu module yang tidak ada di sini diambil dari set yang sama.
