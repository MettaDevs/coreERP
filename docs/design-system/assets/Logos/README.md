# Logos

- `coreerp-logo.png` — tanda produk CoreERP, PNG 570 × 426 dua warna: biru tua untuk huruf C dan dua bilah luar, biru terang untuk bilah tengah. Tidak ada versi satu warna dan tidak ada SVG di sumber.
- Pakai di atas latar putih. Di Shell tanda ini ditaruh di kotak putih 32px berradius `radius-md` (gambar 28px), juga pada tema gelap, karena warnanya tidak dibuat untuk latar gelap.
- Jangan mewarnai ulang, memotong, memutar, atau menggambar ulang tanda ini. Nama dan identitas tenant tidak menggantikannya; keduanya dibaca dari data.
