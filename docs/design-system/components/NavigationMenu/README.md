# NavigationMenu

Menu navigasi horizontal dengan panel isi yang terbuka di bawahnya.

- Pemicu: tinggi 36px, padding 8px × 16px, 14px weight 500, `radius-md`, latar `background`; hover atau terbuka `accent`. Chevron 12px berputar saat terbuka.
- Panel: latar `popover`, border, `radius-md`, bayangan tipis. Tautan di panel: padding `space-2`, `radius-sm`, 14px; aktif `accent` 50%.
- Fokus: cincin 3px `ring`.
- Dipakai di satu layar. Navigasi aplikasi memakai rail dan submenu Shell.
