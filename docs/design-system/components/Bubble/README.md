# Bubble

Gelembung pesan percakapan dengan tujuh varian warna.

- Isi: `radius-xl`, padding 8px × 12px, 14px dengan tinggi baris longgar; lebar maksimum 80% (varian ghost penuh).
- Varian: `primary`, `secondary`, `muted`, tint (`primary` sangat muda; di tema gelap sangat tua), outline (`background` berborder), ghost (tanpa latar), dan destructive (`destructive` 10% dengan teks `destructive`).
- Reaksi: pil kecil `muted` di sudut atas atau bawah dengan cincin 3px `card`.
- Pesan milik sendiri rata kanan.
- Belum dipakai layar mana pun.
