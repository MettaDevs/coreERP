# Toast

Notifikasi singkat di sudut layar untuk hasil yang tidak perlu ditindaklanjuti, misalnya "Tautan disalin."

- Latar `popover`, teks `popover-foreground`, border `border`, radius mengikuti `radius`.
- Ikon 16px per jenis: berhasil `circle-check`, info `info`, peringatan `triangle-alert`, gagal `octagon-x`, memuat `loader-circle` berputar.
- Mengikuti pilihan tema terang/gelap pengguna. Satu penampung toast dipasang sekali untuk seluruh aplikasi.
- **Bukan** satu-satunya tanda Simpan atau proses gagal; kegagalan tampil di FormErrorSummary yang menetap sampai diperbaiki atau ditutup.
