# Tabs

Tab untuk berpindah antar-bagian setara dalam satu area.

- Varian `default`: daftar setinggi 36px, latar `muted`, `radius-lg`, padding 3px; tab aktif berlatar `background` dengan `shadow-sm` (gelap: latar `input` 30% berborder `input`).
- Varian `line`: tanpa latar; tab aktif ditandai garis 2px `foreground` di bawahnya.
- Tab: 14px weight 500, padding 4px × 8px, `radius-md`, teks `foreground` 60% yang menjadi penuh saat hover atau aktif; ikon 16px.
- Orientasi vertikal tersedia: tab selebar daftar, rata kiri.
- Panah berpindah tab; isi tab yang tidak aktif tidak ditampilkan. Fokus: cincin 3px `ring`.
- Dipakai di 9 layar. Bagian kartu record memakai FastTab (CollapsibleSection), bukan Tabs.
