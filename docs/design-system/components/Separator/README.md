# Separator

Garis pemisah 1px `border`, horizontal atau vertikal.

- Horizontal selebar wadah; vertikal setinggi wadah. Di bar perintah tingginya 20px dengan jarak `space-1` di kiri-kanan.
- Bersifat dekoratif, kecuali pemisah kelompok perintah yang memang diumumkan ke pembaca layar.
- Dipakai di 6 layar dan di setiap bar perintah.
