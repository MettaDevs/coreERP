# ContextMenu

Menu klik kanan dengan rupa dan perilaku item yang sama seperti DropdownMenu.

- Panel dan item identik dengan DropdownMenu: `popover`, `radius-md`, `shadow-md`, item 6px × 8px, item destruktif `destructive`.
- Dibuka dengan klik kanan atau tombol menu keyboard di area pemicu.
- Belum dipakai layar mana pun. Aksi per baris tetap di menu `⋯` supaya bisa ditemukan tanpa menebak bahwa klik kanan tersedia.
