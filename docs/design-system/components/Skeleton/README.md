# Skeleton

Kotak bayangan berdenyut sebagai tempat isi yang sedang dimuat.

- Latar `accent`, `radius-md`, animasi denyut; ukurannya meniru isi yang akan datang.
- Hanya untuk pemuatan pertama tata letak. Daftar dan tabel memakai status "Memuat data…".
- Denyut berhenti bila pengguna memilih gerak dikurangi.
- Dipakai di 6 layar.
