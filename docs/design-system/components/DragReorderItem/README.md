# DragReorderItem

Item daftar yang bisa diseret untuk mengubah urutan, dengan bayangan berlabel dan penanda sisip.

- Saat diseret tampil bayangan berlabel. Posisi sisip ditandai garis 2px `primary` di atas atau di bawah item tujuan.
- Urutan tidak berubah selama hover; perubahan baru terjadi saat dilepas.
- Bila urutan penting, sediakan juga cara lewat keyboard.
- Dipakai di satu layar.
