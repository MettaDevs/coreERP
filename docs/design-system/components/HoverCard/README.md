# HoverCard

Kartu pratinjau yang muncul saat kursor berhenti di atas tautan, misalnya ringkasan record.

- Lebar 256px, padding `space-4`, latar `popover`, border, `radius-md`, `shadow-md`.
- Hanya muncul untuk pointer; isinya tidak boleh menjadi satu-satunya jalan ke informasi atau tindakan.
- Dipakai di satu layar.
