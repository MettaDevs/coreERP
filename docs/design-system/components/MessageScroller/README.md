# MessageScroller

Area gulir percakapan yang menempel ke pesan terbaru dan menyediakan tombol kembali ke bawah.

- Jarak antarpesan 32px; scrollbar tipis dengan ruang tetap; tepi bawah memudar.
- Selama pengguna membaca ke atas, gulir otomatis berhenti dan tombol "ke bawah" muncul di tengah bawah; pesan baru tidak merebut posisi baca.
- Pesan di luar layar tidak dirender penuh, sehingga percakapan panjang tetap ringan.
- Belum dipakai layar mana pun.
