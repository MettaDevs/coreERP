# Alert

Pemberitahuan di dalam halaman yang tetap terlihat, dengan ikon, judul, dan isi.

- Bingkai: border, `radius-lg`, latar `card`, padding 12px × 16px, 14px. Kolom ikon 16px berjarak 12px dari teks.
- Varian `default`: teks `card-foreground`, isi `muted-foreground`. Varian `destructive`: teks dan ikon `destructive`, isi `destructive` 90%.
- Judul weight 500 dipotong satu baris (ringkasan error membukanya penuh); isi boleh beberapa paragraf.
- Dipakai di 20 layar; ringkasan error form memakai varian `destructive`.
