# Chart

Wadah grafik dengan tema, tooltip, dan legenda yang seragam; warna seri berasal dari `chart-1` sampai `chart-5`.

- Wadah berasio 16:9, teks 12px. Label sumbu `muted-foreground`; garis kisi `border` 50%.
- Tooltip: latar `background`, border `border` 50%, `radius-lg`, padding 6px × 10px, 12px, `shadow-xl`. Nilai angka tabular weight 500; penanda seri kotak 8px berradius `radius-xs`.
- Legenda di bawah grafik: penanda 8px dan label, jarak antarseri 16px.
- Seri yang kontrasnya lemah (`chart-4` di tema terang, `chart-1` di tema gelap) diberi label atau pola tambahan.
- Dipakai widget grafik pada dasbor analitik Core.
