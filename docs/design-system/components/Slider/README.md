# Slider

Penggeser nilai dalam sebuah rentang, horizontal atau vertikal.

- Lintasan setinggi 6px, bulat penuh, latar `muted`; rentang terisi `primary`.
- Kenop 16px putih berborder `primary`, `shadow-sm`; hover dan fokus memberi cincin 4px `ring` 50%.
- Panah mengubah satu langkah, Home/End ke ujung. Nonaktif: `opacity-disabled`.
- Nilai yang harus tepat tetap disediakan field angka di sampingnya.
- Dipakai di satu layar.
