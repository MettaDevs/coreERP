# Message

Satu pesan percakapan: avatar, kepala (nama atau waktu), isi berupa Bubble, dan kaki.

- Baris 14px berjarak 8px; pesan milik sendiri dibalik ke kanan.
- Avatar bulat berlatar `muted`, sejajar bawah isi.
- Kepala dan kaki 12px weight 500 `muted-foreground`, padding samping 12px.
- Belum dipakai layar mana pun.
