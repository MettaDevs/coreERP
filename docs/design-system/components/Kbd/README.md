# Kbd

Penanda tombol keyboard di dalam teks, misalnya pintasan.

- Tinggi 20px, lebar minimum 20px, padding horizontal `space-1`, `radius-sm`, latar `muted`, teks 12px weight 500 `muted-foreground`, keluarga font yang sama dengan teks.
- Beberapa tombol dikelompokkan dengan jarak `space-1`.
- Tidak bisa diklik dan tidak bisa dipilih. Dipakai di 2 layar.
