# Collapsible

Satu area yang dibuka-tutup oleh pemicunya, tanpa rupa bawaan.

- Komponen hanya mengatur keadaan buka-tutup dan hubungan aksesibel antara pemicu dan isinya; rupanya ditentukan pemakai.
- Bagian kartu berjudul memakai CollapsibleSection; daftar bagian memakai Accordion.
- Dipakai di satu layar.
