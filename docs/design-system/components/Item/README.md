# Item

Baris daftar serbaguna: media, judul, deskripsi, dan aksi dalam satu baris.

- Padding 12px × 16px, jarak 10px, `radius-md`, 14px. Varian tanpa border, `outline` (border `border`), atau `muted`.
- Media: kotak ikon 32px berborder berlatar `muted` dengan `radius-sm`, atau gambar 40px.
- Judul 14px weight 500; deskripsi 14px `muted-foreground`, maksimal dua baris.
- Item yang berupa tautan berlatar `accent` 50% saat hover. Fokus: cincin 3px `ring`.
- Daftar record operasional tetap memakai DataTable. Dipakai di satu layar.
