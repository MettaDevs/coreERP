# Avatar

Gambar profil bundar dengan inisial sebagai cadangan.

- Ukuran 32px (kecil 24px, besar 40px), bulat. Cadangan: inisial 14px `muted-foreground` di atas `muted` (12px untuk ukuran kecil).
- Lencana di kanan bawah: isian `primary` dengan cincin 2px `background`.
- Grup: avatar saling tumpuk 8px dengan cincin 2px `background`; sisanya dihitung dalam lingkaran `muted`.
- Nama orang tetap ditulis di samping avatar; avatar bukan satu-satunya identitas.
- Dipakai di 7 layar.
