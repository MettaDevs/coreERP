# Pagination

Navigasi nomor halaman. Ada di SDK, tetapi **dilarang untuk daftar record**.

- Tautan halaman 36px persegi berupa tombol ghost; halaman aktif bertepi outline. Sebelumnya/Berikutnya berikon chevron; elipsis untuk halaman yang dilewati.
- Semua daftar record, DataTable, pemilih lengkap, dan dropdown record memuat bertahap saat digulir. Tabel dan lookup menolak properti paginasi.
- Hanya sah untuk isi yang memang berhalaman dan bukan daftar record dari database.
- Teks bawaannya masih bahasa Inggris ("Previous", "Next", "More pages"); terjemahkan sebelum dipakai.
- Dipakai di satu layar.
