# Popover

Panel kecil yang melayang di dekat pemicunya, untuk isi interaktif seperti kalender, ribbon melayang, atau filter ringkas.

- Latar `popover` (di dalam form: latar permukaan form), teks `popover-foreground`. Masuk dengan fade dan geser 8px dari arah pemicu.
- Header opsional: judul dan deskripsi 14px `muted-foreground`.
- Klik di luar atau Escape menutup dan mengembalikan fokus ke pemicu.
- Di dalam kartu atau dialog, popover dirender ke wadah lapisan itu.
- Dipakai di 4 layar, serta oleh DatePicker, ribbon RecordActionBar, dan filter kolom DataTable.
