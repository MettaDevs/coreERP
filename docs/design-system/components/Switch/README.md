# Switch

Sakelar menyala/padam untuk setelan yang berlaku langsung atau untuk tanda aktif.

- Ukuran default: lintasan 32 × 18.4px, kenop 16px. Ukuran kecil: lintasan 24 × 14px, kenop 12px. Bulat penuh, `shadow-xs`.
- Lintasan menyala `primary`, padam `input` (tema gelap: `input` 80%). Kenop `background`; di tema gelap kenop menyala `primary-foreground` dan padam `foreground`.
- Kenop bergeser saat diubah. Fokus: cincin 3px `ring`. Nonaktif: `opacity-disabled`.
- Labelnya terpisah di samping (gaya `label`), karena sakelar tidak membawa label di dalam field.
- Record master baru yang punya tanda aktif lahir menyala.
- Dipakai di 26 layar.
