# Marker

Penanda baris dalam alur teks: garis pemisah berlabel di tengah, atau baris keterangan berikon.

- 14px `muted-foreground`, tinggi minimum 16px, ikon 16px.
- Varian pemisah: label di tengah diapit garis 1px `border` kiri-kanan. Varian bergaris: garis bawah `border` dengan padding bawah 8px.
- Tautan di dalamnya bergaris bawah dan menjadi `foreground` saat hover.
- Belum dipakai layar mana pun.
