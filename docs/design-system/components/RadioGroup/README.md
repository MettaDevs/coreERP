# RadioGroup

Pilihan satu dari beberapa opsi yang semuanya terlihat.

- Lingkaran 16px, border `input`, `shadow-xs`; terpilih berisi titik 8px `primary`. Tema gelap: latar `input` 30%.
- Fokus: cincin 3px `ring`. Tidak valid: border dan cincin `destructive`.
- Tab masuk ke opsi terpilih; panah berpindah sekaligus memilih.
- Pakai bila opsinya sedikit dan perbedaannya perlu dibaca berdampingan; daftar panjang memakai Select.
- Dipakai di 6 layar.
