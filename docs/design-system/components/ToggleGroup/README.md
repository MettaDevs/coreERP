# ToggleGroup

Kumpulan Toggle dengan satu atau banyak pilihan aktif, misalnya mengganti mode tampilan atau satuan periode.

- Item memakai rupa Toggle. Jarak antaritem bisa nol (menempel, radius hanya di ujung) atau berjarak; varian `outline` memberi `shadow-xs` pada kelompok.
- Mode tunggal: menyalakan satu item memadamkan yang lain. Mode banyak: setiap item berdiri sendiri.
- Panah kiri/kanan berpindah antaritem; Space atau Enter menyalakan.
- Dipakai di 5 layar.
