# Checkbox

Kotak centang 16px untuk pilihan ya/tidak dan untuk menandai baris tabel.

- Kotak 16px, radius 4px, border `input`, `shadow-xs`. Tercentang: isian dan border `primary`, tanda `check` berwarna `primary-foreground`. Tema gelap: latar `input` 30% saat kosong.
- Fokus: border `ring` dan cincin 3px. Tidak valid: border dan cincin `destructive`. Nonaktif: `opacity-disabled`.
- Labelnya berada di samping, bergaya `label`; mengklik label ikut mengubah centang.
- Di tabel, seluruh sel kolom centang bisa diklik; centang header bisa berkeadaan sebagian. Klik pada kotak centang tidak ikut membuka atau memilih baris.
- Dipakai di 24 layar.
