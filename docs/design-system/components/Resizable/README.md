# Resizable

Panel yang bisa diubah ukurannya dengan divider polos; dasar MasterDetailLayout.

- Divider: garis 1px `border` dengan area seret 4px di kedua sisinya; fokus memberi garis 1px `ring`. Bisa horizontal atau vertikal.
- Pegangan bertitik (16 × 12px, `radius-xs`) **tidak** dipasang kecuali pengguna memintanya. Tanpa pegangan pun divider tetap bisa diseret, menampilkan kursor resize, dan dioperasikan dengan keyboard.
- Dipakai di 3 layar.
