# ScrollArea

Area gulir dengan scrollbar tipis yang sama di semua peramban.

- Scrollbar: lintasan berpadding 1px, ibu jari `border` bulat penuh. Fokus area memberi cincin 3px `ring`.
- Untuk panel kecil seperti menu atau daftar pendek. Daftar dan tabel memakai scroll asli milik DataTable, dengan satu pemilik scroll; jangan menambah ScrollArea di atasnya.
- Dipakai di 3 layar.
