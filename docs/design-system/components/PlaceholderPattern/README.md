# PlaceholderPattern

Pola arsir diagonal untuk mengisi kotak yang belum punya isi, misalnya kerangka halaman awal.

- Garis diagonal dengan jarak 10px yang mengisi seluruh wadah; warna garis ditentukan pemakai.
- Hanya untuk kerangka sementara; jangan tampil di layar kerja yang sudah selesai.
- Dipakai di satu layar.
