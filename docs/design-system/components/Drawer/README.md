# Drawer

Laci yang ditarik dari tepi bawah (atau sisi lain) untuk layar sentuh, dengan pegangan seret.

- Penutup layar `scrim-dialog`; panel berlatar `background`.
- Laci bawah punya pegangan 100 × 8px `muted` berbentuk pil di atasnya.
- Judul semibold dan deskripsi 14px `muted-foreground`; rata tengah untuk laci atas/bawah, rata kiri mulai `breakpoint-md`. Footer padding `space-4`.
- Diseret ke arah tepinya untuk menutup.
- Belum dipakai layar mana pun.
