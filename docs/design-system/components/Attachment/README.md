# Attachment

Kartu berkas: ikon atau gambar kecil, nama, keterangan, dan aksi.

- Kartu: border, `radius-xl`, latar `card`; tiga ukuran (default, sm, xs) dan dua orientasi (mendatar, tegak). Media 40px berlatar `muted` dengan `radius-lg` (sm 32px, xs 28px).
- Nama 14px weight 500 dipotong satu baris; keterangan 12px `muted-foreground`.
- Keadaan: menunggu (border putus-putus), mengunggah atau memproses (nama berkilau, media pudar), selesai, gagal (border `destructive` 30%, keterangan `destructive`).
- Kelompok kartu digulir menyamping dengan snap.
- Belum dipakai layar mana pun; lampiran record hari ini ditampilkan komponen lampiran Core di FactBox.
