# Label

Label teks untuk kontrol yang tidak membawa label di dalam field: Switch, Checkbox, RadioGroup.

- Gaya `label`: 14px weight 500, tinggi baris 1, jarak ke ikon `space-2`. Tidak bisa dipilih sebagai teks.
- Mengklik label memfokuskan atau mengubah kontrolnya. Kontrol nonaktif membuat labelnya ikut pudar 50%.
- Input, Select, dan Textarea tidak memakai Label terpisah; labelnya ada di dalam field. Jangan memakai keduanya sekaligus.
- Dipakai di 5 layar.
