# ContextualTitle

Judul yang sekaligus menjadi pemicu bantuannya: hover sekitar 1 detik untuk mengintip, klik untuk menahan.

- Teks mewarisi gaya judulnya; kursor bantuan; bergaris bawah saat hover, fokus, atau terbuka. Fokus: cincin 2px `ring`.
- Bantuan memakai rupa Tooltip dengan lebar maksimum 320px.
- Pointer dan keyboard memakai target yang sama: Tab ke judul, lalu Enter atau Space.
- Dipakai RecordActionBar dan PageDialog bila judul halaman atau nama fitur punya penjelasan. Jangan menambah ikon bantuan terpisah di setiap judul.
