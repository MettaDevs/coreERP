# Command

Palet perintah: kotak cari di atas daftar hasil yang dikelompokkan; dipakai untuk pencarian menu di Shell.

- Wadah: latar `popover`, `radius-md`.
- Baris cari: tinggi 36px (48px bila dibuka sebagai dialog), garis bawah, ikon `search` 16px pudar, teks 14px.
- Daftar: tinggi maksimum 300px lalu menggulir. Judul kelompok 12px weight 500 `muted-foreground`. Item terpilih berlatar `accent`. Tanpa hasil: teks tengah 14px dengan padding 24px.
- Pintasan di kanan item: 12px `muted-foreground`.
- Penyaringan berjalan saat mengetik; panah atas/bawah memilih, Enter menjalankan, Escape menutup.
- Hanya tujuan yang izinnya dimiliki pengguna yang muncul. Dipakai di 2 layar.
