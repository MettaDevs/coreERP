# Carousel

Deret slide yang digeser satu per satu, horizontal atau vertikal.

- Setiap slide selebar wadah. Tombol sebelumnya/berikutnya bulat 32px (outline) di luar tepi; pada deret vertikal di atas dan bawah.
- Panah keyboard menggeser; tombol di ujung deret nonaktif.
- Nama aksesibel tombolnya masih bahasa Inggris ("Previous slide", "Next slide"); tulis dalam bahasa Indonesia di stack baru.
- Dipakai di satu layar.
