# Spinner

Ikon `loader-circle` yang berputar sebagai tanda sedang memproses.

- Ukuran 16px, warna mengikuti teks di sekitarnya.
- Selalu bersama label proses: "Menyimpan…" pada tombol, "Memuat data…" pada daftar.
- Nama aksesibel bawaannya masih bahasa Inggris ("Loading"); di stack baru tulis "Memuat".
- Dipakai di 20 layar.
