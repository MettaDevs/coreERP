# Menubar

Bilah menu bergaya aplikasi desktop: deretan pemicu yang masing-masing membuka menu.

- Bilah: tinggi 36px, border, `radius-md`, latar `background`, padding `space-1`, `shadow-xs`.
- Pemicu: 14px weight 500, padding 4px × 8px, `radius-sm`; terbuka atau disorot `accent`.
- Panel menu: lebar minimum 192px, `shadow-md`; item sama dengan DropdownMenu; item centang memakai `radius-xs`.
- Saat satu menu terbuka, panah kiri/kanan berpindah ke menu tetangga.
- Dipakai di satu layar. Perintah halaman memakai RecordActionBar, bukan Menubar.
