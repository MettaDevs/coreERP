# CoreERP modules

Namespace publisher untuk module bisnis resmi CoreERP. Module pertama adalah [Procurement](procurement/README.md) dan [Management Asset](management-asset/README.md). Keduanya tetap berada di Application Plane; namespace `coreerp` tidak berarti datanya masuk `core_erp`.

Rujukan: [standar module](../../docs/dev/02-module-standard.md).
