# Modules

Setiap module dibuat di `modules/<publisher>/<module>/` hanya saat diimplementasikan. Satu module wajib memiliki API, UI, database, migration, contracts, deploy manifest, dan container sendiri.

Rujukan: [standar module](../docs/dev/02-module-standard.md), [API dan integration](../docs/dev/04-api-and-integration.md), serta [scope data tenant/org unit](../docs/dev/08-query-scopes-and-schema.md).
