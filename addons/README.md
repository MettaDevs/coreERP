# Addons

Addon customer atau partner dibuat saat ada kebutuhan nyata. Addon memakai SDK dan contract publik; ia tidak mem-fork CoreERP atau mengakses database module langsung.

Rujukan: [customization dan addons](../docs/dev/05-customization-and-addons.md) dan [API governance](../docs/dev/04-api-and-integration.md).
